      Playlists

          Tanzen Music Shuffler · shuffles your Deezer or Spotify dance playlists by genre share and plays them in your own browser tab.
          Deezer tab Preview
          1. Install the Tampermonkey browser extension. In Chrome, also turn on "Allow User Scripts" in the extension's details.
          2. Click Install userscript and confirm in Tampermonkey.
          3. Open exactly one tab on deezer.com, signed in, and click anywhere on the page once (required by the browser's autoplay policy). When Tampermonkey asks to allow access to the server on first connect, choose "Always allow".
          4. When the "Deezer tab" badge (above, and at the top of the page) turns green, press ⏭ Next track.
          1. Install the Tampermonkey browser extension. In Chrome, also turn on "Allow User Scripts" in the extension's details.
          2. Click Install userscript and confirm in Tampermonkey.
          3. Open exactly one tab on open.spotify.com, signed in, and click anywhere on the page once (required by the browser's autoplay policy). When Tampermonkey asks to allow access to the server on first connect, choose "Always allow". Don't play Spotify on another device with the same account at the same time: Spotify then stops the web player.
          4. When the "Spotify tab" badge (above, and at the top of the page) turns green, press ⏭ Next track. The tab moves to the page of each track it plays.
